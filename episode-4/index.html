Épisode 4 Construire le Hero, la vitrine du portfolio

  • Niveau Grand débutant
  • Langages HTML5 · CSS3 · JavaScript
  • Durée indicative 45 à 60 min de vidéo · 3 h en séance
  • Fichier modifié index.html (config.js inchangé)

Objectif de l'épisode

Un recruteur décide en quelques secondes s'il continue à lire : ces secondes-là se passent sur le Hero. Vous allez construire une grille façon salle serveur, un halo qui flotte, le nom qui s'écrit lettre par lettre, un avatar entouré de deux anneaux qui tournent en sens inverse, des badges flottants et des statistiques animées.

Partie 2

Objectif pédagogique

À la fin de cet épisode, vous serez capable de construire un écran d'accueil complet et animé, en combinant la grille Bootstrap, des animations CSS et deux petits programmes JavaScript.

Ce que vous saurez faire

  • Disposer un contenu en deux colonnes avec la grille Bootstrap (row, col-lg-7, col-lg-5).
  • Créer des décors sans image avec ::before, ::after et des dégradés.
  • Écrire une animation CSS avec @keyframes et la propriété animation.
  • Rendre une taille fluide avec clamp() et adapter la page aux petits écrans avec @media.
  • Découper un anneau grâce à un masque CSS.
  • Animer des chiffres et écrire un texte lettre par lettre en JavaScript.

Les nouveaux mots de cet épisode

Les mots des épisodes précédents sont dans les listes des épisodes 1, 2 et 3.

Hero
L'écran d'accueil d'un site, la « vitrine » qu'on voit sans défiler.
Grille Bootstrap
Un système de 12 colonnes : une rangée (row) contient des colonnes (col-lg-7 = 7 colonnes sur 12 à partir de 992 pixels).
Animation CSS
Une suite d'étapes décrite par @keyframes, jouée par la propriété animation.
@keyframes
Les « images clés » d'une animation : l'état au départ (from), à l'arrivée (to), ou à des pourcentages.
transform
Déplacer (translate), agrandir (scale) ou tourner (rotate) un élément, sans changer la mise en page.
clamp()
Une valeur bornée : clamp(minimum, idéal, maximum).
vw / vh
1 % de la largeur (vw) ou de la hauteur (vh) de la fenêtre.
Media query
Une règle @media : du CSS qui ne s'applique que sous ou au-dessus d'une certaine largeur d'écran.
Masque CSS
Un « pochoir » : seules les zones couvertes par le masque restent visibles.
Dégradé conique
Un dégradé dont les couleurs tournent autour du centre, comme les aiguilles d'une horloge.
let
Comme const, mais pour une valeur qui va changer (un compteur, un drapeau).
requestAnimationFrame
Demander au navigateur d'exécuter une fonction à la prochaine image affichée : la base des animations fluides en JavaScript.

🧩 Lire une animation CSS

      animation: spinRing 8s linear infinite;
    @keyframes spinRing { to { transform: rotate(360deg); } }

La propriété animation dit quoi jouer (le nom spinRing), combien de temps (8 s), comment (linear = vitesse constante) et combien de fois (infinite). La règle @keyframes du même nom décrit ce qui change : ici, un tour complet.

Erreur 1 Le nom et le métier apparaissent deux fois

Symptôme
L'ancien nom de l'épisode 3 reste affiché au-dessus ou en dessous du Hero.

Symptôme
Un grand disque coloré tourne derrière l'avatar.
Cause
Une ligne du masque manque ou est mal écrite (lignes 292 à 302), par exemple mask-composite.
Solution
Copiez à nouveau les lignes 277 à 305 depuis le code complet.
Vérification
Seul un arc fin et lumineux tourne.

Erreur 3 Une animation ne bouge pas

Symptôme
Le halo, le point, les badges ou la flèche restent immobiles.
Cause
Le nom dans animation ne correspond pas exactement à celui de @keyframes (floatglow au lieu de floatGlow), ou la règle @keyframes manque.
Solution
Les deux noms doivent être identiques, majuscules comprises.
Vérification
Outils de développement › menu ⋮ › Plus d'outils › Animations (Chrome) : les animations apparaissent.

Symptôme

Le module des compteurs manque, la classe counter-anim ou l'attribut data-target est mal écrit, ou une erreur JavaScript bloque le script.
Solution
Lisez la Console, puis comparez les lignes 505, 510, 515 et 576.
Vérification
Après un petit défilement, les chiffres montent.

Symptôme
Le nom reste vide, ou s'affiche d'un coup sans animation.

Exercice pratique : votre propre Hero

Consigne

  1. Remplacez « Lucas Moreau » par votre nom, aux deux endroits nécessaires.
  2. Changez la statistique « 15+ compétences techniques » pour qu'elle affiche votre propre nombre de compétences.
  3. Vérifiez : votre nom s'écrit lettre par lettre, et votre compteur monte jusqu'à votre nombre.
💡 Afficher l'aide

Le nom affiché vient du HTML (ligne 477) ; le nom tapé vient du JavaScript (ligne 609).

La valeur d'arrivée d'un compteur est dans son attribut data-target (ligne 505). Le 0 entre les balises est seulement la valeur de départ.

Exemple pour Camille Durand, avec 12 compétences :

              <span id="typing-name">Camille Durand</span><span class="typing-cursor" aria-hidden="true"></span>
                <div class="stat-val"><span class="counter-anim" data-target="12">0</span><span>+</span></div>
      const text = 'Camille Durand';

Pourquoi deux endroits pour le nom ? Le HTML garantit que le nom existe sans JavaScript ; le JavaScript a besoin de connaître le texte à taper. Pensez aussi au aria-label du logo, à la description du Hero et aux métadonnées de l'épisode 1 (author, description).

Partie 14 · facultatif

Défi pour aller plus loin : démonter l'astuce du masque

Supprimez provisoirement les deux lignes -webkit-mask-composite: destination-out; (ligne 296) et mask-composite: exclude; (ligne 302). Prédisez ce que vous allez voir, vérifiez, puis remettez-les.

Sans la combinaison des couches, les deux masques s'additionnent : toute la surface reste visible. On voit alors un disque coloré plein qui tourne derrière l'avatar, au lieu d'un arc fin.

Avec exclude (ou destination-out), on retire l'intérieur (padding-box) de la surface totale : il ne reste que la bordure transparente de 2 pixels, où le dégradé conique apparaît. C'est l'astuce « anneau en CSS pur » annoncée dans l'introduction de l'épisode.

Remettez les deux lignes pour rester identique au code de la série.
