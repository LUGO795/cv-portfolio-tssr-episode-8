Épisode 5 Construire « À propos de moi »

  • Niveau Grand débutant
  • Langages HTML5 · CSS3 · JavaScript
  • Durée indicative 30 à 45 min de vidéo · 2 h 30 en séance
  • Fichier modifié index.html (config.js inchangé)

Objectif de l'épisode

Un beau Hero donne envie au recruteur de lire la suite ; la section À propos doit lui donner envie d'appeler. Vous allez construire une présentation qui raconte un parcours, une liste d'arguments qui répond à « pourquoi lui ? », une carte Google Maps intégrée à la page, et un composant réutilisé dans toutes les sections suivantes : l'apparition au défilement.

Partie 2

Objectif pédagogique

À la fin de cet épisode, vous serez capable de construire une section de contenu complète, d'intégrer un service extérieur (une carte) et de faire apparaître des éléments quand ils entrent dans l'écran.

Ce que vous saurez faire

  • Écrire des styles communs à toutes les sections (sur-titre, titre, séparateur) pour ne plus les répéter.
  • Disposer des informations avec une grille CSS (display: grid) et des colonnes Bootstrap.
  • Intégrer une page extérieure avec <iframe>, en pensant à son title et à son chargement différé.
  • Préparer un état caché en CSS (opacity, transform, transition) et le déclencher en JavaScript avec IntersectionObserver.
  • Piloter un composant Bootstrap depuis JavaScript (refermer le menu mobile).
  • Comprendre pourquoi un style écrit par JavaScript peut perdre contre une règle CSS !important.

Les nouveaux mots de cet épisode

Les mots des épisodes précédents sont dans les listes des épisodes 1, 2, 3 et 4.

Section « À propos »
La partie du portfolio qui présente la personne : parcours, situation, arguments.
Sélecteur de type
Un sélecteur qui vise une balise par son nom : section { … } touche toutes les <section>.
Grille CSS
display: grid range les enfants d'un élément en lignes et en colonnes ; grid-template-columns dit combien de colonnes et de quelle largeur.
fr
Une « fraction » de l'espace libre : 1fr 1fr = deux colonnes égales.
<iframe>
Un cadre qui affiche une autre page web à l'intérieur de la vôtre (ici, Google Maps).
Chargement différé
loading="lazy" : le navigateur attend que le cadre approche de l'écran pour le charger.
transition
Un passage en douceur d'une valeur à une autre quand une propriété change (opacité, position…).
IntersectionObserver
Un « guetteur » fourni par le navigateur : il prévient le script quand un élément entre dans la zone visible.
Verre dépoli
Un effet de carte semi-transparente qui floute ce qui se trouve derrière (backdrop-filter: blur()).
Style en ligne
Un style écrit directement sur un élément (style="…" dans le HTML, ou element.style en JavaScript).
!important
Un mot-clé qui fait passer une déclaration CSS avant toutes les déclarations normales, y compris les styles en ligne.

🧩 Le principe de l'apparition, en trois lignes

    .reveal { opacity: 0; transform: translateY(30px); transition: … }
    .reveal.visible { opacity: 1; transform: translateY(0); }
            if (e.isIntersecting) { e.target.classList.add('visible'); obs.unobserve(e.target); }

Le CSS décrit deux états : caché (transparent, 30 pixels plus bas) et visible. La transition dit comment passer de l'un à l'autre. Le JavaScript se contente d'ajouter la classe visible au bon moment : quand l'élément entre dans l'écran.

Partie 14 · facultatif

Défi pour aller plus loin : changer le sens d'apparition

Le CSS prévoit une classe reveal-left (ligne 441) que la page n'utilise pas encore. Ajoutez-la à la colonne de gauche (ligne 643) pour qu'elle arrive depuis la gauche, sans écrire de CSS ni de JavaScript. Puis expliquez pourquoi ça marche, alors que .reveal demande déjà un translateY.

          <div class="col-lg-7 reveal reveal-left">

.reveal et .reveal-left ont le même poids (une classe chacune). À poids égal, la dernière règle écrite gagne : .reveal-left (ligne 441) est écrite après .reveal (ligne 437), donc son transform: translateX(-30px) remplace le translateY(30px). L'opacité 0 et la transition, elles, viennent toujours de .reveal.

À l'arrivée, .reveal-left.visible (ligne 443, deux classes) remet la position à translateX(0), et le module 4 n'a rien à savoir : il ajoute visible à tous les éléments reveal.

Retirez ensuite reveal-left pour rester identique au code de la série.
